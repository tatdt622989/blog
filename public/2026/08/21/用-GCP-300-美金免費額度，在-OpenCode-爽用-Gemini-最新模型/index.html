GCP 300 美金免費額度實戰：OpenCode 串接 Gemini 3.8 Flash 教學

可以用 GCP 300 美金免費額度在 OpenCode 寫程式。 Google Cloud 新戶的 300 美元試用金（效期 90 天）可以折抵 Agent Platform（原 Vertex AI） 上的 Gemini 用量：在 Agent Studio 建一把 API Key，貼進 OpenCode 的 Vertex 設定，就能用 Gemini 3.8 Flash 等模型，試用期間不會自動扣款。要注意兩個例外：AI Studio 的 Gemini API 與 Claude 等合作夥伴模型都不能用這筆試用金折抵。

本文專注在 OpenCode 串接與用量控制，資料查核日期為 2026 年 10 月 19 日。試用金的申請資格、信用卡驗證與完整限制，請看 Google Cloud 300 美金免費試用完整教學。

300 美金能折抵哪些 AI 用量

用途 能否用試用金折抵 依據
Agent Platform 上的 Gemini 模型（OpenCode 走的路線） 可以 官方未排除；筆者帳單實測 Vertex AI 費用全數由抵免額沖銷
AI Studio 的 Gemini API 不行 官方：試用金不能支付 AI Studio 的 Gemini API 費用
Claude 等以託管 API 提供的合作夥伴模型 不行，試用期也不能用 Marketplace 同上
申請提高配額 試用期不能申請 同上
Google AI Pro 每月 10 美元 另計的獨立抵免額，可疊加使用 Google 官方部落格

所以 OpenCode 裡請只選 Gemini 模型；想用 Claude 得另外付費，且要先升級成付費帳戶。

300 美金能用多少 Token

以下為 Agent Platform 官方價格（global 端點，每 100 萬 Token）：

模型 輸入 / 輸出 快取輸入 300 美金約可換

  • Coding Agent 每輪都會重送大量上下文，輸入 Token 遠多於輸出；快取輸入只要原價的十分之一，所以實際能用的量通常比單算輸入價更多。

步驟一：確認試用金已入帳

  1. 依 試用教學 開通 Free Trial，並建立一個專用專案（例如 ai-coding-sandbox）。
  2. 選用：有訂閱 Google AI Pro 的話，到 Google Developer Program 福利頁 每月領取 10 美元的 Gen AI 與 Cloud 抵免額：

  1. 到 Billing → Credits，確認 Free Trial 300 美元與月度抵免額都已入帳：

步驟二：啟用 Agent Platform API 並建立 API Key

Vertex AI 已更名為 Gemini Enterprise Agent Platform，主控台簡稱 Agent Platform，API 也改叫 Agent Platform API。

  1. 在主控台搜尋並啟用 Agent Platform API。
  2. 打開 Agent Studio 的 API 金鑰頁，建立一把 API Key。
  3. 建議在金鑰設定加上 API 限制，只允許 Agent Platform API；官方提醒拿到金鑰的人都能花你的配額。官方 API Key 說明

用 API Key 不需要安裝 gcloud CLI，也不用設定 Service Account。另外，官方還有一種免綁卡的 express mode 免費方案（限 @gmail.com 帳號、90 天、配額較低），它和 300 美金試用金是兩套不同的方案，不要混在一起。express mode 說明

步驟三：在 OpenCode 連上 Vertex 並選模型

  1. 在 OpenCode 輸入 /connect，選 Vertex，貼上 API Key。也可以改用環境變數：
  1. 輸入 /models，切換到 Gemini 3.8 Flash。

模型怎麼選：

模型 適合 備註
Gemini 3.8 Flash 日常主力 1M 上下文、最多 65,536 輸出 Token；推理等級只有 LOW / MEDIUM / HIGH。官方規格；新功能見 Gemini 3.8 Flash 介紹
Gemini 3.7 Flash 想省 Token 同價位，官方建議重視運算效率時改用 3.7
Gemini 4 Argon 困難的長任務 價格約 Flash 的 2.7 倍，12/1 起再翻倍；見 Gemini 4 Argon 價格與限制

如果連線出現認證錯誤，先檢查環境裡是否同時設了 GOOGLE_CLOUD_PROJECT、VERTEX_LOCATION 等專案或區域設定。OpenCode 在有明確專案或區域時可能改走 ADC（gcloud 登入）認證，而不是 API Key。

監控用量，避免超支

Token 用量：到 Agent Studio 用量主頁 看每日輸入與輸出 Token：

折抵明細：到 Billing → Reports，確認 Vertex AI（Agent Platform）的費用都由抵免額沖銷、實付為 0：

升級成付費帳戶後，到 Billing → Budgets & alerts 設預算。一般預算只發通知、不會自動停止用量；要硬上限請改設 spend cap 預算，它支援 Agent Platform，專案花費超過預算時會自動暫停新請求，直到下個預算週期。官方 spend cap 說明

90 天到期或額度用完會怎樣
