Google Cloud 300 美金免費額度：資格、90 天期限、能用範圍與防扣款

Google Cloud 給從沒付費過的新客戶 US$300 的 Welcome credit（免費試用金），從註冊起 90 天內有效。試用期間不會收費；額度用完或 90 天到期時，資源會被停止，只要你沒有手動升級成付費帳戶，就不會自動扣款。要注意的是，AI Studio 的 Gemini API 不能用這筆錢，但在 Google Cloud 上透過 Gemini Enterprise Agent Platform（前身 Vertex AI）呼叫 Gemini 可以。

以下資料以 Google Cloud 官方文件為準，查核日 2026-10-19。

重點一覽

項目 內容
金額 US$300 Welcome credit
期限 從註冊起 90 天，不能暫停或延長
試用期間收費 不收費
結束條件 額度用完、滿 90 天、或你手動升級，三者先到者
到期後 資源停止，進入 30 天寬限期，之後永久刪除
自動扣款 不會；只有升級成付費帳戶後，超出額度的用量才會扣款

來源：Google Cloud Free Program 官方說明、Free Trial 條款。

誰可以領

官方列出的資格只有兩條，必須同時符合（來源）：

  • 從來不是 Google Cloud、Google Maps Platform 或 Firebase 的付費使用者
  • 以前沒有申請過 Free Trial

另外，條款 §1.2 排除美國與墨西哥的政府機關。

註冊時要注意：

  • 必須綁信用卡或其他有效付款方式，部分國家還要驗證銀行帳戶。這是用來驗證身分和防詐騙。
  • 註冊後會出現一筆 US$0～1 的授權預扣，不是實際扣款，通常幾天到一個月內會釋放。
  • 官方付款方式與幣別表中，台灣的帳單幣別是新台幣（TWD），付款方式是信用卡或簽帳金融卡。主控台上的金額因此可能以新台幣顯示，實際以帳單頁為準。
  • 不接受的付款方式：預付卡、需要雙重驗證的簽帳金融卡。

申請入口：console.cloud.google.com/freetrial。完成後會自動建立一個叫 My First Project 的專案和一個叫 My Billing Account 的試用帳單帳戶。

300 美金能花在哪、不能花在哪

用途 能否使用試用金 依據
Compute Engine、Cloud Run、BigQuery、Cloud Storage 等多數 Google Cloud 產品 可以，也能抵超出 Always Free 的部分 Free Program
Gemini Enterprise Agent Platform（前身 Vertex AI）上的 Gemini 模型 可以 Gemini 平台產品頁 FAQ
AI Studio 的 Gemini API 不行 Gemini API 計費 FAQ
Model Garden 以託管 API（model as a service）提供的第三方生成式 AI 模型 不行 Free Program
挖加密貨幣 禁止 條款 §3.2

試用帳單帳戶在升級之前還有這些限制：

  • 不能幫 VM 加 GPU
  • 不能用 Google Cloud Marketplace
  • 不能申請提高配額
  • 不能建立 Windows Server VM
  • 不能建立 Google Cloud VMware Engine 資源
  • Compute Engine 同時最多使用 8 核心（條款 §3.1）

Gemini 要走對入口

同樣是 Gemini，帳怎麼算取決於你從哪裡拿金鑰：

  • 從 AI Studio 建立的 Gemini API 金鑰：走 Gemini API 計費，官方明確寫「Welcome credit 或免費試用金不能用於 Gemini API 或 AI Studio」。這條路要用 Gemini API 的免費層或預付方案。
  • 在 Google Cloud 主控台啟用 Agent Platform API（API 服務名稱 aiplatform.googleapis.com）：用量算在 Google Cloud 帳單，會從 300 美金扣抵。

實際設定步驟可以看這篇：用 GCP 300 美金免費額度，在 OpenCode 爽用 Gemini 最新模型。

90 天到期或額度用完會怎樣

沒升級的話，試用帳單帳戶會自動關閉，接著依序發生（來源）：

  1. 專案停用計費，所有在試用期間建立的資源被停止，Compute Engine 等服務裡的資料被標記為待刪除。
  2. 失去 Google Cloud 產品的存取權，可能收到「帳單帳戶已取消或停權」的通知。
  3. 進入 30 天寬限期：這段時間內升級成付費帳戶，可能救回被停止的資源和資料。
  4. 寬限期結束仍未升級，試用期間的資源永久刪除。

整個過程不會向你的卡片收費。如果你在乎資料，要在到期前自己備份或升級。

升級成付費帳戶後有什麼不同

試用帳單帳戶 付費帳單帳戶
收費 不收 超出剩餘試用金、Always Free 額度，或不在試用範圍內的產品，會從付款方式扣款
剩餘試用金 可用 保留，但仍在原本註冊後 90 天到期
GPU、Marketplace、第三方模型 不可用 解鎖
到期時的資源 停止 繼續運作，不中斷

升級步驟（需要是該帳單帳戶的 Billing Account Administrator）：

  1. 開啟主控台的 Welcome 頁面
  2. 點工具列上的 Activate
  3. 在確認對話框再點一次 Activate

帳單總覽頁的 Free credit 面板上也有同一個 Activate 按鈕。升級前先把下面的預算設好，因為升級後才開始有真正的扣款風險。

Always Free 和 300 美金試用金差在哪

300 美金試用金 Always Free（Free Tier）
性質 一次性額度 每月固定用量上限
期限 註冊後 90 天 無結束日（Google 可提前 30 天通知調整）
對象 新客戶 任何有效帳單帳戶，試用或付費都算
用不完 到期作廢 不累積到下個月

常用的 Always Free 額度（完整清單）：

產品 每月免費額度
Compute Engine 1 台 e2-micro（限 us-west1、us-central1、us-east1）、30 GB-月標準永久磁碟、北美出站流量 1 GB
Cloud Storage 5 GB-月（限 us-east1、us-west1、us-central1）、5,000 次 Class A、50,000 次 Class B 操作
BigQuery 查詢 1 TiB、儲存 10 GiB
Cloud Run 200 萬次請求、360,000 GB-秒記憶體、180,000 vCPU-秒
Firestore 每專案 1 GiB 儲存；每天 50,000 次讀取、20,000 次寫入、20,000 次刪除

GPU 和 TPU 不在 Always Free 內，一律收費。

Always Free 需要一個有效的帳單帳戶。試用到期沒升級，帳單帳戶會關閉，也就沒辦法繼續用 Always Free；想長期使用就得升級。如果只是要免費部署網站或 API，也可以參考 Cloudflare 免費服務圖鑑。

怎麼查剩多少額度

  1. 在主控台點左上角導覽選單 → Billing → Overview（或直接開 console.cloud.google.com/billing/overview）
  2. 有多個帳單帳戶時，選試用的那一個
  3. 帳戶類型若顯示 Free trial account，代表不會被收費；Free credit 面板會顯示剩餘金額與剩餘天數

想知道錢花在哪個服務，開 Billing → Reports：試用金扣抵的金額列在 Other savings 欄，Usage cost 欄則是如果沒有試用金時的原價（來源）。

避免意外帳單

試用期間不升級，最壞情況是資源被停，不會被扣款。真正的風險在升級之後，以下設定建議在升級前完成。

設定預算提醒

路徑：Billing → Budgets & alerts → Create new budget（官方步驟）。設定金額和提醒門檻（例如 50%、90%、100%），超過時會寄信。

注意：一般預算只會寄提醒，不會自動停用服務，費用照算。

用 spend cap 擋住 API 暴衝

Spend cap 預算會在超過金額時自動暫停服務，但限制很多：

項目 說明
支援服務 只有 Gemini API、Gemini Enterprise Agent Platform（前身 Vertex AI）、Cloud Run、Cloud Run functions
範圍 每個預算只能綁一個專案的一個服務，週期固定為每月
計算方式 用未扣除任何折扣與試用金的估算原價判斷，所以試用金還有餘額時也可能先觸發暫停
不會停的東西 VM、儲存空間這類持續性資源照樣計費
即時性 不是即時，觸發前已超出的部分照樣收費

把 Gemini 接到寫程式工具這類可能大量呼叫的場景，最適合用 spend cap 擋住。

用完就關

官方建議的止血方式（來源）：

  • 把用量控制在 Always Free 範圍內
  • 關閉或刪除不用的資源
  • 對專案停用計費
  • 直接關閉帳單帳戶，停止所有計費服務
