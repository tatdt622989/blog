AI 寫程式訂閱比較 2026：Claude Code、Codex、Cursor、Copilot 價格與額度

結論（2026 年 10 月 19 日查核官方價格頁）：只想花 $10，選 GitHub Copilot Pro；$20 價位想要最多 agent 用量，選 Claude Pro（含 Claude Code）或 ChatGPT Plus（含 Codex）；每天重度使用再升 $100 到 $200 的 Claude Max 或 ChatGPT Pro。Cursor 10 月 12 日起改賣 X 訂閱，新方案內含額度只給 Grok 模型，用 Claude、GPT 要另外按 API 牌價付費。

2026 年 10 月價格總表

以下為個人方案美元月費，不含稅；資料日期 2026-10-19。

工具 方案與月費 額度怎麼算 可用模型
Claude Code Pro $20（年繳約 $17／月）、Max 5× $100、Max 20× $200 每 5 小時 + 每週上限，與 Claude app 共用；Max 為 Pro 的 5／20 倍 Opus、Sonnet、Haiku；Fable 在 Max 最多占週額度 50%
Codex Free、Go $8、Plus $20、Pro $100／$200／$500 Plus 依模型估算每 5 小時訊息數；Pro 目前沒有 5 小時上限，只有週額度 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Luna
GitHub Copilot Free、Pro $10、Pro+ $39、Max $100 每月 AI Credits（1 credit = $0.01）：1,500／7,000／20,000；程式補全不扣點 Pro 為部分模型，Pro+ 起含 premium 模型
Cursor（X 訂閱） Plus $8、Premium $30、Super $100、Ultra $200 與 Grok 共用每週額度；Premium、Super、Ultra 為 Plus 的 4、15、50 倍 內含額度只限 Grok；第三方模型需 Premium 以上並按 API 牌價另計

來源：Claude 定價、Max 方案說明、Codex 定價、Copilot 方案、Cursor 定價。

哪個最划算？依預算選

每美元能換多少用量：Copilot 與 Cursor 的第三方模型是按 API 價格扣款，Copilot 含 flex 額度約為月費的 1.5 到 2 倍，Cursor 用 Claude、GPT 則是 1 倍。Claude 與 ChatGPT 沒有公布 token 數，我的 Atlas 排行榜 10 月 19 日的多來源估算從數倍到數十倍都有，最高樣本是 Claude Max 5× 約 77 倍、ChatGPT Plus 約 22 倍，屬研究估算而非官方保證。倍率怎麼算、怎麼避開陷阱，見 AI 訂閱怎麼買最划算。

Claude Code 方案：Pro 還是 Max？

  • Claude Pro 起就含 Claude Code，Free 不含。Pro 用 Fable 要另買 usage credits，Max 則可用到週額度的 50%。
  • **9 月 14 日起週上限改為促銷前基準的 125%**，比促銷期間的 150% 少約 16.7%；5 小時上限不受這次調整影響。官方公告、官方補充
  • Max 附的每月 $100／$200 API credits 不能用在 Claude Code，超出額度後的 usage credits 以 API 價格計費。Anthropic 說明

Codex 要買哪個 ChatGPT 方案？

  • Plus $20 每 5 小時大約可發 GPT-6.1 Sol 15 至 160 則、GPT-6 Astra 5 至 45 則、GPT-6 Luna 350 至 3,000 則本機訊息，另有週上限。
  • Pro 分 $100、$200、$500 三檔，目前都沒有 5 小時上限；只有 $500 方案有 Ultrafast。$200 方案 9 月 10 日曾暫停新訂閱，9 月底已恢復，但新訂戶額度有調整。
  • Free 與 Go 也能用 Codex 做輕量任務（GPT-6 Luna，逐步開放）；GPT-5.5 已於 10 月 14 日從 Codex 退役。Codex 定價

新模型與 Pro 500 的來龍去脈見 OpenAI DevDay 2026 總整理；額度用完怎麼辦見 Codex 額度指南。

Cursor 改成 X 訂閱後，還值得買嗎？

  • 10 月 12 日起 Cursor 與 Grok、X Premium 綁成 X 訂閱，Premium $30 含原本 Cursor Pro 的權益。xAI 公告
  • 內含額度只給 Grok：Plus 只能用 Grok 模型；Premium 以上可在 Cursor 用第三方模型，但要先儲值、按 API 牌價扣款。
  • 舊 Cursor 訂戶不會被自動轉換，可維持原方案、價格與內含的第三方模型用量，自行切換時會按比例退費。

如果你主要用 Claude 或 GPT 寫程式，現在直接訂 Claude Pro 或 ChatGPT Plus 比走 Cursor 划算；Cursor 的價值在編輯器與 Agent 介面。三者功能差異見 Claude Code、Codex、Cursor 功能比較。

GitHub Copilot 方案與 AI Credits

  • 6 月 1 日起全面改用 AI Credits：基本額度等於月費，再加會變動的 flex 額度（Pro $5、Pro+ $31、Max $100）。GitHub 公告
  • 程式補全與 next edit suggestions 在付費方案不扣點，所以只要補全的人，Pro $10 就夠。
  • Pro+ 與 Max 可把任務派給 Claude、Codex 等第三方 coding agent（預覽中）；Pro 起含 Copilot cloud agent。
