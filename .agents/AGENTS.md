# 專案撰寫規則 (Project Rules)

## 文章排版與標籤規則
* **一律禁止使用表情符號 (Emoji)**：文章的大標題、副標題 (H2、H3、H4 等，即目錄/目次中會出現的標題) 以及內文，一律禁止使用 Emoji 表情符號，以維持部落格的專業與簡潔排版。
* **嚴格沿用既有標準標籤 (Tags)，禁止自行創造相似標籤**：新文章的 tags 一律優先沿用站內既有的核心標準標籤（如：`獨立開發者`、`遊戲開發`、`前端開發`、`AI`、`OpenAI`、`Claude`、`Codex`、`Aseprite`、`日語學習` 等），嚴禁自行發明或創造語意高度相似但字面上不同的重複標籤（例如：禁止創立 `獨立開發` 來分散 `獨立開發者`），以維持全站標籤系統的乾淨與權重聚合。
