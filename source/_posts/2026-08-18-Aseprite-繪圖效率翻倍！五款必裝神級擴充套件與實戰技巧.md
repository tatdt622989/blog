最值得裝的五款 **Aseprite 擴充套件**：免費的 **Lospec Palette Importer**（調色盤搜尋匯入）、**Magic Pencil**（自動描邊、噴濺、圖層分離）、**Isometric Guidelines**（等角網格），以及各 5 美元起的 **Wave Warp**（波浪動畫）與 **Parallixel**（視差背景）。安裝方式是 **Edit → Preferences → Extensions → Add Extension** 選取檔案；注意試用版不能執行腳本，外掛也無法使用。

下面整理每款外掛的官方下載頁、版本需求、核心功能與實際使用時要注意的限制（2026 年 10 月核對）。

## Aseprite 擴充套件怎麼安裝？

**.aseprite-extension 擴充套件**（上表除 Isometric Guidelines 外皆是）：

1. 下載檔案；若是 **.zip**（例如 Magic Pencil），先解壓縮取出 **.aseprite-extension**。
2. 開啟 **Edit → Preferences → Extensions**，點 **Add Extension** 選取檔案（[官方擴充套件文件](https://www.aseprite.org/docs/extensions/)）。也可以直接雙擊檔案或拖曳進 Aseprite 視窗，再按確認。
3. 確認清單中已勾選啟用；部分外掛（如 Magic Pencil）建議重新啟動 Aseprite。

**.lua 腳本**（Isometric Guidelines）：

1. 點 **File → Scripts → Open Scripts Folder**（[官方腳本文件](https://www.aseprite.org/docs/scripting/)），把 **.lua** 放進該資料夾。
2. 點 **File → Scripts → Rescan Scripts Folder** 或重開軟體，之後從 **File → Scripts** 執行。

擴充套件不能當成腳本使用：把 Wave Warp、Parallixel 這類套件丟進 Scripts 資料夾不會生效。

## Aseprite 下載與試用版限制

- **試用版**：[官方試用頁](https://www.aseprite.org/trial/)目前提供 v1.3.18.6，限制是無法存檔；依開發者與社群回報，試用版也停用腳本功能，因此**本文所有外掛都無法在試用版運作**。
- **正式版**：從[官網購買](https://www.aseprite.org/buy/)（可附 Steam 金鑰）或在 [Steam](https://store.steampowered.com/app/431730/Aseprite/) 購買。
- **自行編譯**：原始碼公開於 [GitHub](https://github.com/aseprite/aseprite)，編譯出的版本可使用外掛。

三種取得方式的步驟比較見 [Aseprite 安裝教學：踏進 AI Pixel Art 的第一步](/2026/06/15/aseprite-install-guide/)。

## Lospec Palette Importer：上千款社群調色盤一鍵匯入

![Lospec Palette Importer 調色盤搜尋與匯入視窗（來源：itch.io / sudo whoami）](lospec-palette-importer-search.png)

- **開發者**：sudo whoami（John Riggles），最新版 v1.6.0（2026 年 3 月）
- **下載**：[itch.io 專案頁面](https://sudo-whoami.itch.io/lospec-palette-importer) / [GitHub 原始碼](https://github.com/JRiggles/Lospec-Palette-Importer)

省去「瀏覽器搜尋 Lospec → 下載 **.gpl** → 手動匯入」的流程：

1. **直接搜尋**：點色票上方的選單（**≡**）→ **Import Palette from Lospec**，輸入名稱（如 Endesga 32、PICO-8）。
2. **相似名稱推薦**：名稱不完全符合時列出相近的調色盤，預設 5 個，可在偏好設定調為 3 到 10 個。
3. **靈感來源**：提供隨機調色盤與 Lospec 每日調色盤。
4. **保留出處**：預設存成 **.gpl**，會保留作者、顏色數與 Lospec 連結；存成 **.aseprite** 則不含這些資訊。

首次使用時需選 **Give full trust to this script**，讓它呼叫 curl 連線 Lospec 並寫入檔案。官方只支援 Windows 與 macOS，Linux 除了 **Open In App** 之外大致可用但未經官方保證。

## Magic Pencil：Aseprite 自動描邊與圖層分離外掛

![Magic Pencil 擴充套件功能面板與繪圖選項（來源：itch.io / Kacper Woźniak）](magic-pencil-panel.png)

- **開發者**：Kacper Woźniak，最新版 v2.0.5
- **下載**：[itch.io 專案頁面](https://thkaspar.itch.io/magic-pencil)（Windows / macOS / Linux）

從 **Edit → Magic Pencil** 開啟面板，選好模式後用任何繪圖工具作畫即可套用，不必來回切換工具：

| 分類 | 模式 | 作用 |
| :--- | :--- | :--- |
| Effect | **Brush Outline** / **Graffiti** | 筆劃自動加外框；隨機噴濺雜點，適合髒污、磨損、岩石質感 |
| Transform | **Lift** / **Merge** / **Select** | 把劃過的像素抽到新圖層；把劃過區域的可見圖層合併到新圖層；以筆刷建立選取 |
| Change | **Outline** / **Colorize** / **Desaturate** / **Shift** | 對劃過的像素加外框、上色、去飽和或平移色相明度 |
| 選項 | **Indexed Mode** | 改色時只使用調色盤內的顏色，不產生新色 |

v2.x 不相容 1.3-rc4 以前的 Aseprite；開發者建議使用最新版。

## Isometric Guidelines：2.5D 等角網格產生器

![Aseprite Isometric Guidelines 等角透視網格輔助線產生預覽（來源：itch.io / Noesteryo）](isometric-guidelines-preview.png)

- **開發者**：Noesteryo
- **下載**：[itch.io 專案頁面](https://noesteryo.itch.io/aseprite-isometric-guidelines)（**.lua** 腳本）

等角（Isometric）像素圖要遵守 2:1 斜率，Aseprite 原生格線只有矩形，手拉輔助線容易歪。這支腳本可設定地板或牆面的方格大小、是否產生牆面，並分別指定地板、左牆、右牆的線條顏色。執行後會**產生一份新的 Sprite**，在新檔核對好尺寸再把網格帶進素材專案。

## Wave Warp：像素水波、旗幟與熱氣扭曲動畫

![Wave Warp 像素波浪扭曲與旗幟動態生成效果（來源：itch.io / Devkidd）](wave-warp-animation.gif)

- **開發者**：Devkidd，最新版 v1.0.1（2025 年 7 月）
- **下載**：[itch.io 專案頁面](https://devkidd.itch.io/wave-warp)，5 美元起

1. **波形**：正弦、三角、方波、鋸齒、圓形等。
2. **參數**：振幅、頻率、方向、速度、相位，套用前可即時預覽。
3. **Pinning 錨點**：固定頂部、底部、側邊或中央，例如做旗幟時固定旗桿那一側。
4. **光影**：可加光照與陰影、選擇是否反鋸齒，支援多圖層與群組圖層。

限制：依開發者在留言區的說明，目前是從**單一選取的 Cel** 產生動畫，不會套用到既有的多影格動畫上。產生後仍要自己檢查首尾銜接。

## Parallixel：橫向捲軸視差背景一鍵生成

![Parallixel 橫向卷軸遊戲視差背景動態預覽（來源：itch.io / Devkidd）](parallixel-preview.gif)

- **開發者**：Devkidd，最新版 v1.2.0（2026 年 3 月）
- **下載**：[itch.io 專案頁面](https://devkidd.itch.io/parallixel)，5 美元起

1. **自動視差**：對所有圖層套用視差並可調整速度，也能只捲動選取的圖層、Cel 或區域。
2. **方向與角度**：支援八個方向，以及等角、45 度與自訂角度。
3. **靜態與動畫圖層皆可**：產生無縫循環，在匯入 Unity、Godot 前先抓出接縫破綻。
4. **其他**：Tiled Mode 平鋪預覽、MotionPath（直線、弧線、波浪、晃動、圓形等路徑）。

注意：開發者以 Aseprite 1.3.14-beta1 開發測試，並提醒 1.3.15 之後的版本可能運作不如預期，購買前先看頁面上的最新相容性說明。

## 依製作階段搭配

1. **定色調**：Lospec Palette Importer 套用調色盤。
2. **畫靜態素材**：Isometric Guidelines 打透視骨架，Magic Pencil 描邊與改色。
3. **加動態**：Wave Warp 做特效動畫，Parallixel 驗證背景循環。
